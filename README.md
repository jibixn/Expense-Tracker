# Expense Tracker App

A simple Expense Tracker web application built using **HTML, CSS and JavaScript**.

## Files
- `index.html` - Application structure 
- `style.css` - Custom styling 
- `app.js` - Application logic, Local Storage handling, calculations, and chart

## Features Included
1. **Add Transaction**: Add income or expense transactions with Amount, Category, Date, and Description.
2. **Edit & Delete**: Edit any existing transaction or delete it with a click.
3. **Totals & Balance**: Real-time display of Total Income, Total Expenses, and Current Balance.
4. **Filtering**: Filter transactions by Type (All, Income, Expense) or by Category.
5. **Local Storage**: Automatically persists all transaction data so it remains after refreshing the page.
6. **Responsive with media queries**
7. **Monthly Summary**: Summarizes expenses and income grouped by month.
8. **Category-wise Expense Chart**: HTML5 canvas chart displaying category-wise expense distribution and percentages.
9. **Validation & Errors**: Clear validation and helpful inline error messages for invalid amount, empty description, date, and category.

### Option 1: Direct in Browser
